# Market Risk Analytics

A small, auditable version of a bank's daily market risk workflow, built on public
data. Each run loads market data, checks it, values a trading book, measures risk,
explains what changed since yesterday, and reports it.

> Independent portfolio project. Not affiliated with or endorsed by Goldman Sachs or
> any other firm. The trading book is synthetic; all market data and filings used are public.

## What it does

- **Data you can trust.** 15 automatic checks on every run (missing, stale or
  duplicate prices, futures rolls, dividend adjustments, position reconciliation,
  reporting deadline), and every number traced back to the raw file it came from.
- **Risk measures.** Value-at-Risk and Expected Shortfall by three methods, with full
  revaluation of every position.
- **Is the model right?** A daily backtest since January 2024, with the Kupiec and
  Christoffersen tests and the Basel traffic light.
- **What if?** Stress tests replaying Lehman 2008, COVID 2020 and the 2022 UK gilt
  crisis, plus simple shocks.
- **Why did it move?** Each day's change in VaR is split into trades, market moves and
  the scenario window rolling forward.
- **Reporting.** A one-page written commentary, an HTML dashboard, and a 6-page
  Power BI report.
- **Case study.** 16 years of Goldman Sachs' published VaR, parsed from 67 SEC filings,
  compared with public market data, with an honest account of what can and cannot be
  inferred.

## Key results (29 Sep 2026)

| Method | 99% VaR | 97.5% ES | Exceptions since Jan 2024 (expected 6.9) |
|---|---:|---:|---:|
| Historical simulation, equal weights (primary) | GBP 3.00m | GBP 3.40m | 5 |
| Historical simulation, age-weighted | GBP 3.00m | GBP 2.94m | 10 |
| Parametric (normal) | GBP 1.81m | GBP 1.82m | 14 |

- The normal-distribution model fails its backtest (twice the expected exceptions):
  real returns have fatter tails.
- The primary model gets the count right, but its exceptions cluster. Its five-year
  window dropped the COVID crash days one by one in early 2025, VaR fell 47%, and the
  April 2025 sell-off then breached it three days running.
- Public market volatility explains at most about 18% of the quarter-to-quarter changes
  in Goldman's published VaR.

Full results and method: [docs/METHODOLOGY.md](docs/METHODOLOGY.md).

## Quick start

Requires Python 3.9 or later.

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # macOS/Linux: .venv/bin/python
.venv/Scripts/python -m riskengine run --as-of 2026-09-29
.venv/Scripts/python -m pytest
```

The first run downloads market data from 2007 and takes about 20 seconds; add
`--offline` to replay the saved files. The case study needs a contact for SEC's
fair-access policy:

```bash
SEC_USER_AGENT="Your Name your@email" .venv/Scripts/python -m riskengine casestudy
```

## How the numbers are checked

- Independent scripts recompute VaR, ES, every backtest day and every stress scenario
  with hand-written formulas, and match the engine (`tools/verify_var.py`,
  `tools/verify_stress.py`).
- Every data check is tested by injecting the fault it is meant to catch.
- The Power BI report's numbers are read back from Power BI's own engine and matched
  against the source data (`tools/verify_powerbi.ps1`).
- 47 automated tests.

## Limitations

- Market data comes from free sources; `yfinance` is unofficial and can change without notice.
- Bonds are modelled as zero-coupon bonds on curve points; commodities use fund returns
  as a roll-free proxy for futures.
- VaR is one-day only. The book's trades are random, so position changes have no
  business reason behind them.
